# Besluiten

Besluiten per project: wat is er besloten, door wie (rollen), op basis van welke argumenten en wat is de volgende stap.

Naamconventie: `YYYY-MM-DD-<project-slug>-<korte-omschrijving>.md`

Voorbeeld: `2026-07-29-llm-wiki-start-pilot.md`

Gebruik `schema/besluit-template.md` voor nieuwe bestanden.
De agent maakt besluitbestanden aan op basis van goedgekeurde notities in de lokale inbox.
