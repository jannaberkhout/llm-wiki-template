# Projecten

Één submap per project. De mapnaam is de slug van het project (lowercase, koppeltekens).

Naamconventie: `<korte-naam>/index.md`

Voorbeeld: `llm-wiki/index.md`

Elke projectmap bevat minimaal één `index.md` op basis van `schema/project-template.md`.
Aanvullende bestanden (research, bijlagen) komen in dezelfde submap.

De agent maakt submappen aan bij de eerste ingest van een nieuw project.
Maak hier zelf geen mappen aan — dat verstoort de index.
