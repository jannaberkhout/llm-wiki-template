# Projects

One subfolder per project. The folder name is the project's slug (lowercase, hyphens).

Naming convention: `<short-name>/index.md`

Example: `llm-wiki/index.md`

Every project folder contains at least one `index.md` based on `schema/project-template.md`.
Additional files (research, attachments) go in the same subfolder.

The agent creates subfolders at the first ingest of a new project.
Do not create folders here yourself — that breaks the index.
