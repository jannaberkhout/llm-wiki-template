# Decisions

Decisions per project: what was decided, by whom (roles), based on which arguments and what the next step is.

Naming convention: `YYYY-MM-DD-<project-slug>-<short-description>.md`

Example: `2026-07-29-llm-wiki-start-pilot.md`

Use `schema/decision-template.md` for new files.
The agent creates decision files based on approved notes in the local inbox.
