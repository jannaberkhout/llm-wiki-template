# Decision template

Use this template for decisions in `wiki/decisions/`.
Naming convention: `YYYY-MM-DD-<project-slug>-<short-description>.md`

Example: `2026-07-29-llm-wiki-start-pilot.md`

---

```yaml
---
title: 
aliases: []
tags: [decision]
status: draft
project: 
decision: go
date: 
contributed-by: []
generated-by: 
date-created: 
sources: []
---
```

**`project`** — slug of the project the decision belongs to (the folder name in `wiki/projects/`).

**`decision`** — the outcome, one of: `go` · `no-go` · `park` · `stop` · `adjust`. Adapt this list to your own decision-making.

**`status`** — the status of the page itself (`draft` or `active`), not of the decision.
